# Limits and next work

## Current reference scope

Single-item presence qualification, metal vote/mean-moisture classification, uncertainty rejection and a timed two-servo routing cycle. No trained model, DC motor/conveyor, object-recognition camera, bin-full sensor, scale, persistent counts or dashboard is included.

## Next priorities

1. Confirm original hardware and mechanics; reconcile pins and actuator design before using reference code.
2. Specify a suitable metal-sensor interface and validate every supply/signal voltage.
3. Calibrate moisture/metal sensing using controlled representative samples; measure unknown and error rates.
4. Validate selector/gate movement, retention, release and actuator current on a bench.
5. Add actual photos/video, confirmed contributions and recorded tests.
6. Add exit/position/jam feedback and a defined reject path before claiming robust automatic disposal.
7. If needed, add persistent statistics or a network dashboard with separate validation.
8. Conveyor/DC-motor or AI-camera variants require a separately engineered control/power design and labelled evaluation data.

Moisture does not determine recyclability, organic composition or hazardous status. Mixed/dirty samples, sensor fouling, corrosion and object geometry can change decisions. Industrial handling, liquid/sharp/battery disposal and reliable waste-category compliance are outside this demonstration.
